状态说明：

- `✅`：当前 beta.8 正式代码已落地，并有相应测试、浏览器回归或本机验证证据。
- `🟡`：仅用于尚未完成的外部人工平台验收，不再用于已经落地的 UI / Web 能力。
- `⚠️`：能力存在，但仍有人工验收、发布条件或准确性门槛未闭环。
- `❌`：没有。

社群容量与设备状态也已覆盖 100 / 200 成员、单批 50，以及多设备 1 / 2 / 4、同机重登轮换、停用和历史保留。beta.7 → beta.8 的本机临时原地迁移已验证可保留 120 日历史、设置和社群状态；原 beta.7 App 与 App Support 已由哈希原样恢复并重新运行，迁移副本位于 `/private/tmp`。

当前未闭环的只有真实外部阻断：Intel Mac 与 Windows 10/11 的人工可见界面端到端验收；可信 Developer ID / Team ID、公证和 HTTPS 更新源；以及未经授权的生产、发布、合并和部署。原本机 Keychain 继承已不可用，若既有成员继承失败，只能补发其设备码，不得新建成员。其他模型/产品仍不得在缺少真实安全字段时冒充原生支持。
