## 验收结论

beta.8 候选已经完成 Swift 分享卡与最终页面真实渲染、服务端 SQLite／PostgreSQL、Web、浏览器联调、Windows 跨平台、universal 构建、安装失败自动回滚与真实原地升级。奥哥已完成主要视觉审核，并接受设置通用页的信息层级作为 beta.9 视觉债。远端 `ace51c1e9c1ebc6d89c0e4cc693ec15ebbee4837` 已通过四项 CI 和本机单屏“重新打开主窗口”实测；它包含对当前生产 beta.7 公开榜行的客户端兼容，以及 Web 分享预览的真实载入门禁。生产公开榜仍返回 beta.7 行结构且尚无 beta.8 签名个人排名路由：旧响应缺少主力工具／模型时客户端仍展示真实公开榜且不伪造维度；单独的个人排名读取失败时只中立提示暂不可用，不把任意网络或服务器错误归因为部署状态。分享预览在浏览器真实解码成功前保持隐藏且“保存图片”不可用；载入失败不会显示破图或保存空内容。

本机对现有 `0.1.0-source.1` 的真实原地替换已先完成两份独立备份和一份桌面可见完整备份。首次安装在签名 Helper 时被 macOS Keychain 拒绝，安装器自动回滚且旧 App、固定社群 origin、本地 usage／settings／team sync 与 SQLite 均未变；用户在可见终端解锁登录钥匙串后，第二次安装成功升级到 `0.1.0-beta.8`。升级后关键状态哈希、SQLite `quick_check`、原 `device_id`／`device_public_id` 与社群服务器保持不变，真实同步成功且未创建重复成员或设备。这一路径使用本机自签身份，不要求 Apple Developer 账号。

这不是生产发布授权：当前 CI 证据仅对应 Draft PR #4 的 `ace51c1e9c1ebc6d89c0e4cc693ec15ebbee4837`。任何后续提交都必须重做同一精确 head 的完整检查；更早提交及其 Actions 只用于追溯，不得冒充当前候选。

## 用户可见能力范围

- TokenFleet 单圈目标圆环、圈数和真实超额百分比；系统右侧原生菜单栏入口固定启用，旧自动／刘海左／刘海右设置统一迁移为原生菜单栏，不再提供会遮挡其他状态项的 Token Island。
- MacBook 内置屏菜单栏拥挤时，原生圆环可能被 macOS 隐藏；App 运行期间从应用程序或 Spotlight 再次打开 TokenFleet 会直接找回并置前唯一主窗口，最小化窗口也会恢复。登录启动仍只进入菜单栏，不抢占前台。
- 在 beta.8 服务端契约部署后，快览、主窗口社群页和分享内容可显示本人排名、参榜人数、超过成员比例、最近同步时间、连续活跃与相对近 7 个活跃日节奏；本人在 Top 10 外仍从签名只读响应取得自己的公开主力工具、模型与估算字段。客户端先升级、服务端仍为 beta.7 时，App 会继续显示真实公开榜，对缺失的主力维度显示空值；单独的个人排名读取失败时会中立显示“暂不可用”，不会误报成“未加入社群”，也不会在客户端猜测具体失败原因。
- 历史 7 / 30 / 90 天按 Asia/Shanghai 连续日历桶计算，采集器省略的零用量日会补零而不会向更早活跃日扩张；活动墙分别使用 1 / 5 / 13 列，“全部”使用 34 列，并按所选日历窗口顺序填充，跨周的近 7 天不会漏掉窗口起点。
- 九套主题、版本化 API 标准价估算与覆盖率／未计价状态、分享卡渲染、复制 PNG、保存 JPEG 的错误边界均已纳入验证。
- 管理员可对既有成员补发 60 分钟一次性设备码；同一事务失效旧的未使用有效码，不新增重复成员、不占批次名额，也不更改已使用码与审计记录。
- 采集侧遵循安全样本和隐私边界；仅成功且确有用量记录的来源计入“已采集客户端”。

## 数据影响与回滚

- beta.8 不要求新增服务端数据库列或 schema 迁移。连续活跃和日历范围由既有本地 `DailyUsage` 日桶计算；设备码补发复用既有 enrollment token 数据，只在事务内处理旧未用码失效；本人排名为设备签名鉴权的只读公开口径接口，并新增本人公开主力工具、模型和聚合费用字段，不返回设备或私密资料。
- 客户端升级会涉及本地应用与 SQLite 数据的迁移路径。已验证的回滚方式是：升级前备份 beta.7，使用临时 beta.8 完成迁移和验证后，按备份哈希恢复原 beta.7，并执行 SQLite 完整性检查和回归运行。
- 任何实际发布前须保留 beta.7 安装包、用户本地数据库备份、更新前版本与可回退安装路径；发生迁移或启动异常时停止推送，恢复 beta.7 与相应备份，不对生产成员数据做破坏性清理。
- 当前未部署 beta.8 生产 API 字段，因而本地证据不改变生产服务数据、成员状态或更新源。
