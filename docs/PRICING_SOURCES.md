## 生效依据与历史回填

优先采用官方明确的价格生效日期；官方只给当前价、未说明生效日期时，按已批准规则采用该型号在账本的首次出现日，并在价格版本中记下依据。这里不写入成员数据或账本日期；正式录入时由服务端解析。

每周新补录的型号只自动补算原来没有价格的 exact 行。已有价格版本、价格结果、非 exact 行、删除标记与私有计价均排除；首次全面历史校正另走预览、备份和已授权的重算操作。周检只能使用价格专用管理 API 和专用凭据，不能通过共享 ECS 执行改库命令。
