# TokenFleet beta.8 更新与迁移状态

状态：beta.8 的 Swift、Web 与本机数据兼容性已完成当前范围的实现和验证；**生产发布、合并、部署均未获授权**。当前成员仍可沿用固定仓库 commit 的源码安装／手动升级路径，该路径不要求付费 Apple Developer 账号；在可信签名和更新基础设施补齐前，不得宣传在线自动更新或公开公证安装包。

## 已落地的 beta.8 能力

- Swift 已落地单屏入口、今日页、历史四层（总览 / 按工具 / 按模型 / 每日明细）、App 内社群 Top 10、排名海报和四段设置。
- Web 已落地动态工具/模型筛选、主力工具优先展示、安装与参与页、二维码说明文案，以及真实 1200 × 1600 排名海报。
- 社群边界已测试：100 / 200 成员、单批最多 50 个成员；多设备 1 / 2 / 4、同机重登轮换、停用和历史保留均已验证。

## 已完成的本机 beta.7／旧源码版 → beta.8 真实原地升级

奥哥本机已经按正式源码安装路径完成真实原地升级，而不只是在临时副本中演练：

1. 升级前分别备份旧 App、完整 `~/Library/Application Support/TokenFleet` 和偏好，并对 usage／settings／team-sync 与 SQLite 做哈希和完整性检查。
2. 首次安装因登录钥匙串未授权在签名阶段失败；安装器自动恢复旧 App，数据与团队身份未改变。
3. 用户在可见终端解锁登录钥匙串后重试成功，正式 App 原地升级为 `0.1.0-beta.8`；随后又完成主窗口重新打开修复的同路径升级。
4. 升级前后本地历史、设置、固定社群 origin、`device_id`、`device_public_id` 与原成员连接均保持一致；真实同步成功，未新增重复成员或设备。
5. 回滚脚本仍保留每次替换前的已验证旧 App，桌面另有完整 App Support 备份，可恢复后再做 SQLite `quick_check`。

这证明现有邀请制源码安装用户具备可回滚的手动升级路径；它**不**证明 beta.7 用户能通过在线更新自动升级到公开公证安装包。当前对其他成员的升级说明可固定到 Draft PR #4 已独立复核且四项 CI 全绿的 `ace51c1e9c1ebc6d89c0e4cc693ec15ebbee4837`；若该 PR 再有提交，必须改用新的精确 commit 并重新验证，不得笼统使用浮动分支。

客户端与服务端可以分阶段升级：beta.8 客户端会兼容当前生产 beta.7 的公开榜行，在主力工具／模型字段缺失时只显示空值，不伪造数据；签名个人排名接口尚未部署或读取失败时会中立显示“暂不可用”。完整个人排名与分享排名要等 beta.8 服务端契约另行获批部署后才可验收。

## 仍然阻断公开公证包与在线自动更新的外部条件

- 没有可信的 Apple Developer Team ID、Developer ID 签名或公证凭据。
- 没有受控的 HTTPS 更新源，因此无法安全提供更新清单和安装包。
- 当前源码安装器依赖每台 Mac 的稳定本机自签身份，并已验证对应 file-login Keychain 路径；它不等于 Apple 公证信誉，也不能冒充未来 Developer ID 包的 Keychain 迁移结论。
- 若既有成员继承失败，只能为该既有成员安全补发设备码；不得借此新建成员，也不得占用或突破邀请批次边界。

因此 beta.8 当前可表述为已实现、完成本机兼容性验证，并支持固定仓库 commit 的源码安装／手动升级；不能表述为可在线自动推送、已有公开公证安装包，或已经发布。

## 未来获授权后的迁移原则（不构成执行授权）

1. 若未来决定增加公开公证包或在线自动更新，再取得可信 Team ID、Developer ID、公证能力和独立 HTTPS 更新端点；这不是当前源码安装的前置条件。
2. 用签名且公证的 universal 安装包，在隔离设备复测 beta.7 覆盖安装、数据保留和 Keychain 继承。
3. 若 Keychain 继承失败，仅向已存在且未绑定的成员补发设备码；不创建新成员。
4. 发布前单独确认更新源、成员通知、回滚和生产影响；没有该授权不得部署、合并或发布。

## 回滚与数据边界

- 当前本机已运行 beta.8；每次原地替换前的旧 App 都进入 `SourceInstall/backups`，完整数据另有升级前桌面备份，恢复路径由哈希与 SQLite 完整性检查保护。
- 将来任何升级或回滚都不得删除本地历史、设置或社群数据，也不得操作未授权的服务或网站。
- 生产更新源、签名包、成员通知与实际发布均为后续独立授权事项。
