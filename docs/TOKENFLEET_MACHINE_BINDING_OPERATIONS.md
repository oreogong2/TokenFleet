# 机器绑定客户端的服务端回退边界

beta.14 起客户端请求签名包含机器摘要。服务端不可直接回退到 `b72c34d8e901` 机器绑定迁移及对应验签实现之前：旧服务端无法验证新版签名，客户端会收到认证失败并要求重新连接。不要用批量重连、删除设备或清除客户端凭据来掩盖不兼容。

常规应用回退必须保留机器绑定字段及兼容验签协议，数据库迁移维持 `b72c34d8e901` 或后续兼容版本。确需回退到更早协议时，先另行审批并在隔离副本演练客户端、服务端及数据迁移方案，再安排维护窗口。本版本没有执行这类回退或生产旧行清理。

备份、演练和恢复程序参见 [运维说明](TOKENFLEET_OPERATIONS.md)。本说明不授权执行回退、清理或凭据重置。
