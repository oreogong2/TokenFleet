报告日期：2026-08-15

分支：`codex/tokenfleet-beta8`
状态：视觉主流程已由奥哥审核；本地候选已固定，发布前修复、远端新 CI、本机永久替换和生产发布仍未完成

## 一、前因与目标

beta.7 在 2026-08-11 完成首批邀请测试后，真实使用暴露了两类问题：一是 App 与 Web 的视觉和信息层级不一致，部分页面仍保留旧 TokenStep 结构；二是 beta.8 所需的历史日历口径、榜外本人信息、多设备补码、100／200 人容量、费用真实性、源码更新边界等尚未形成完整验收闭环。

本轮没有修改 beta.2–beta.7 tag 或历史，也没有新建 clone／worktree。所有正式代码均直接接续当前正式仓库既有未提交工作树。

## 二、两日迭代完成内容

### 1. Swift App 视觉与交互

- 将已确认 HTML 视觉方向落地为真实 SwiftUI：菜单栏单屏入口、今日、历史、App 社群榜、分享排名、设置四段页。
- 删除会遮挡其他状态项的 Token Island／刘海悬浮入口；beta.8 固定使用 macOS 原生右侧菜单栏。旧 `automatic/notchLeft/notchRight` 设置统一迁移为 `menuBar`。
- 今日页的工具／模型按当前范围真实数据展示。模型按 Token 量降序，默认 Top 3，超过 3 个可展开全部；历史概览按选中范围聚合 Top 3，工具／模型／每日明细页保留全量。
- 历史默认范围为“全部”。总量与明细使用全部历史；受固定画布限制，热力图与趋势明确展示最近 34 周（238 天），不再把 34 周误写成全部图形。
- 修正 7／30／90 天为 Asia/Shanghai 连续日历桶，补齐零用量日；修正活动墙跨周漏日、范围截图未继承当前 tab／范围等问题。
- App 社群页保留两个真实动作：分享排名（复制／保存）和打开匿名排行榜；截图渲染环境下外部动作按安全规则禁用，不伪造成功。
- 海报统一为 1200×1600 PNG，左侧仅姓名与 Token，右侧为适中字号排名／总人数；Top 10、二维码、单位和底部 slogan 已按奥哥逐轮视觉反馈对齐。榜外本人仍通过签名只读接口取得真实本人公开字段。
- 设置“检查更新”在源码安装版明确显示暂不可用且不发网络请求；不伪装在线更新。

### 2. Web 公榜、安装与分享

- 公榜与分享图统一为同一视觉层级；主力工具优先于主力模型，工具／模型筛选支持动态多项。
- 排名 hero 的昵称、Token、排名和总人数按统一页边距对齐；移动端右侧不再溢出。
- 分享图、网页分享预览和 App 分享排名统一到同一海报结构，不再出现两套不同布局。
- 安装页二维码只写“扫码添加微信领取邀请码”，不显示奥哥姓名或头像。
- “排行榜”和“安装与加入”均连接真实路由；演示／截图环境使用本地演示 origin 时不会冒充生产可用。

### 3. 服务端、成员与多设备

- 明确“单批最多 50，可创建多个批次”，不是社群总人数最多 50。
- 100／200 人、多批次、同步和排行榜容量测试已覆盖，并保持单批 50 的安全边界。
- 管理员必须为既有成员补发 60 分钟设备码；1／2／4 台设备绑定同一 `user_id`，各设备独立、用量按成员聚合。
- 补码不创建重复成员、不占邀请批次；同一事务失效该成员其他未使用且未过期的旧码，已使用码和审计记录保留。
- 测试了同机重新登记轮换 secret、旧历史保留、单台设备停用和成员聚合。
- 匿名公榜只返回显式公开投影；本人榜外详细字段必须走设备签名只读响应，不泄露私密成员或设备信息。

### 4. 费用、采集与跨平台边界

- 费用统一标记为“API 公开标准价估算”，支持版本化价格、覆盖率和“未定价”，不冒充真实账单／订阅总支出。
- 连续活跃、Agent 工作强度和缓存复用均使用明确口径；Agent 强度不混入 Token 主图。
- 保持采集器隐私边界：支持来源日志仅在本机只读处理；prompt、回复和代码字段不进入统计或上传，本地路径与请求／会话标识只作为增量定位和去重元数据。WorkBuddy 因日志混合内容保持不支持；Kimi／DeepSeek 仅在真实 CC Switch 代理行存在时作为实验来源。
- App 与 Helper 均构建为 universal `arm64 + x86_64`；Windows 保留源码候选与安装生命周期门禁，真实 Windows GUI 人工 E2E 仍是外部限制。

若原成员升级后 Keychain 设备凭据确实无法继承，只能在后台选择该既有成员补发设备码并重新连接；不得重新走邀请批次或新建成员。服务端不做破坏性 schema 迁移，原成员、排名和历史不应改变。

## 六、后台管理台日常使用

后台是 FastAPI 同源站点的根路径，不是 Swift App 隐藏页；`/rank` 是匿名公开榜。生产后台 URL、管理员账号保管／找回和值班告警交接目前没有进入公开仓库，因此不能声称已经具备完整生产运维交接。

日常社群运营建议：

1. 登录私有后台根地址，在“总览”检查最近同步、在线设备、异常归零／突增和未定价。
2. 新成员在“成员”创建短时、按实际人数的邀请批次；单批 1–50，可建多批，链接仅私发，外传立即关闭。
3. 老成员新增设备、重装或码过期，必须选中已有成员“补发设备码”，不要重新创建参赛者。
4. 丢失单台设备只禁用该设备；成员退出则关闭公开榜、禁用成员并逐台禁用设备，历史按留存策略保留。
5. 模型价格变化只新增正确生效日的新版本，不篡改历史；公开价才勾选用于匿名榜估算。
6. 后台不包含 readyz、错误率、备份、数据库空间和告警面板；这些属于外部系统运维，不应与日常社群运营混为一谈。
